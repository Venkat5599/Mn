# @pitchside/sdk

Everything an app or bot needs to talk to Pitchside on Monad, and the single source of truth the
relayer, the Chainlink CRE workflow and the frontend all share.

| Module | What it is |
|---|---|
| `client` | `PitchsideClient`: typed reads (room, market, standings) and writes (create, join, bet, settle, cash out) with measured gas limits |
| `abi` | `pitchOracleAbi`, `pitchsideRoomsAbi`, `mockAusdAbi` (generated by `bun run abi`) |
| `outcome`, `mapping` | the Outcome enum and the MLB call → Outcome table |
| `feed` | flattens MLB `feed/live` into numbered pitches, game snapshot |
| `confirm` | the independent check each CRE node runs, and the report encoding |
| `payout` | the contract's parimutuel math, for UIs |
| `chains`, `constants`, `deployment`, `drip` | Monad chains, gas limits, protocol constants, deployment files, drip message |

```ts
import { PitchsideClient, Outcome, monadTestnet, parseDeployment } from "@pitchside/sdk";
import { createPublicClient, http } from "viem";

const px = new PitchsideClient({
  publicClient: createPublicClient({ chain: monadTestnet, transport: http() }),
  deployment: parseDeployment(await Bun.file("deployments/10143.json").json()),
});
const market = await px.getOpenMarket(1n);
console.log(market.seq, market.open, market.lockAt);
```
